# 🖥️ Веб-приложение баз данных «Коворкинг-центр»

## 📝 Общие сведения о проекте
Данный программный комплекс представляет собой современное кроссплатформенное серверное веб-приложение, разработанное в рамках курсового проекта по дисциплине **«Разработка приложений баз данных для информационных систем»** на кафедре *«Информационные технологии»* ГГТУ им. П.О. Сухого.

Приложение предназначено для комплексной автоматизации операционной деятельности коворкинг-центров, ведения прозрачного учета материально-технических ресурсов, фиксации входящих финансовых потоков и контроля наработанного клиентами времени визитов.

---

## 🛠️ Программно-технический стек
При разработке системы использовались передовые технологии и стандарты платформы **.NET 9.0**:
* **Язык программирования:** C# 13 (строгая типизация данных, асинхронность, паттерн DI)
* **Архитектурный шаблон:** ASP.NET Core MVC (разделённые слои Models, Views, Controllers)
* **Система управления базами данных:** Microsoft SQL Server (LocalDB)
* **Объектно-реляционное отображение (ORM):** Entity Framework Core 9.0 (Подход Code-First, Миграции)
* **Клиентский интерфейс:** HTML5, CSS3, микрофреймворк Bootstrap 5.3 (адаптивная вёрстка)
* **Фреймворк тестирования:** xUnit + Microsoft.EntityFrameworkCore.InMemory (виртуальная БД в ОЗУ)

## 🚀 Ключевые функции и реализованная бизнес-логика

1. **Защита от овербукинга (Двойного бронирования):** Интегрированы жесткие серверные валидаторы интервалов времени `TimeSpan`. Любые попытки забронировать один и тот же рабочий стол (1–20), кабинет (1–8) или переговорную комнату (1–10) на пересекающиеся часы блокируются на уровне ядра системы с выводом предупреждения.
2. **Динамический расчет стоимости :** Формы снабжены JavaScript-калькуляторами, которые мгновенно пересчитывают часовые и дневные тарифы в зависимости от выбранного класса оборудования (Базовое, Стандарт, Бизнес, Премиум).
3. **Учет времени аренды по резидентам:** Реализован алгоритм сквозного суммирования наработанного времени. Расчеты перенесены на сторону СУБД, что обеспечивает мгновенное открытие статистических карточек.
4. **Оптимизация под большие массивы данных:** Внедрена серверная пагинация (постраничный вывод по **15 записей на экран**). База данных при первом старте автоматически генерирует **10 200 записей** с помощью механизма `.UseSeeding()`, при этом интерфейс работает без задержек благодаря операторам `Skip` и `Take`.
5. **Каскадная целостность данных:** На уровне реляционных связей СУБД настроено правило `ON DELETE CASCADE`. При удалении резидента автоматически очищается вся история его броней и чеков, исключая «записи-сироты».

## 🏗️ Структура репозитория
* `/Controllers` — классы-диспетчеры маршрутизации веб-запросов (`ResidentsController`, `WorkplacesController` и др.).
* `/Models` — POCO-классы сущностей предметной области (`Resident`, `Booking`, `Payment`, `MeetingRoom`).
* `/Views` — графические шаблоны страниц со встроенным Razor-синтаксисом.
* `/Data` — контекст базы данных `AppDbContext` и класс инициализации больших данных.
* `/Services` — слой чистой изолированной бизнес-логики (`CoworkingService`).
* `CoworkingCenter.Tests/` — проект автоматизированных Unit и интеграционных тестов (фреймворк xUnit).

## ⚡ Инструкция по локальному развертыванию
Для запуска проекта на локальной рабочей станции программиста необходимо выполнить следующие команды в терминале:

```bash
# 1. Клонировать репозиторий на компьютер
git clone https://github.com

# 2. Перейти в папку с проектом
cd CoworkingCenter

# 3. Восстановить зависимости и скомпилировать решение
dotnet restore
dotnet build

# 4. Запустить веб-приложение
dotnet run --project CoworkingCenter.csproj
```
После запуска откройте браузер и перейдите по адресу: **`http://localhost:5092`**. База данных `CoworkingFinalDb2` создастся и наполнится демонстрационными данными автоматически при самом первом запуске.
